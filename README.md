# Photo Site（フォトサイト） [3周目]

CODEJUMP 入門編の「フォトサイト／1カラム」課題として制作しているWebサイトです。（基礎固めの3周目）

## 概要

「写真集を出版することになった友人からの依頼」という架空の案件設定のもと、紹介用のWebページ（1ページ）を制作しています。

CODEJUMPの課題を通して、HTML・CSSの基礎構造やレイアウト設計、レスポンシブ対応について学習しています。

## コーディング仕様・学習内容

- **コンテンツ幅**: メインビジュアル 1000px / 中のコンテンツ 600px
- **INDEX セクション**: 白背景
- **DETAIL セクション**:
  - 画像とテキストの横並び配置
  - 著者・出版社・発行年エリアの上下に罫線配置
- **レスポンシブ対応**:
  - ブレークポイント 1024px
  - レスポンシブ時は DETAIL コンテンツを縦積みに配置
- **Git / GitHub**: バージョン管理

## 使用技術

- HTML5
- CSS3
- Git / GitHub
